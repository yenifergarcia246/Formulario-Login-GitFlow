# Proyecto: Login GranCole

## Descripción  
Este proyecto presenta un formulario de inicio de sesión moderno y responsive para el sistema GranCole.  
Incluye campos con íconos, validación básica en JavaScript y un diseño limpio con colores institucionales.

---

## Características principales  
- Diseño atractivo y sencillo  
- Totalmente responsive (se adapta a diferentes pantallas)  
- Íconos integrados con Font Awesome  
- Validación de campos con JavaScript  
- Footer con derechos de autor  

---

## Tecnologías utilizadas  
- HTML5 → estructura del formulario  
- CSS3 → estilos y diseño responsive  
- JavaScript → validación de usuario y contraseña  
- Font Awesome → íconos de usuario y candado
